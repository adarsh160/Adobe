How to review

  • Click or tap the UI as you would on a phone. Menus, sheets, search and the page links all work.
  • The “3 min read” row opens the page info sheet. The side-panel icon at the right of the docs bar opens the IDocs navigation.
  • Tap anywhere else to flash every clickable area. H keeps them on.
  • Hover an area to see where it goes.
  • Long pages scroll inside the phone.

Shortcuts

  • Esc or ← back
  • R restart
  • H tap areas

Good paths to try

  • Menu ☰ → Docs → IDocs
  • Docs bar → Practices → Well Architected Framework → WAF Overview
  • Search → “waf” → See all → open a result
  • WAF page → “On this page” row
  • Collection from the landing page
